HTML Lists

1. Unordered Lists (<ul>)

Used for collections where items do not follow a strict chronological sequence.

  • Shopping List
  • Grocery Shopping
  • To-Do Items
  • Apples
  • Bananas
  • Milk
  • Bread

2. Ordered Lists (<ol>)

Used for sequential data, step-by-step guides, or ranked items.

  1. Create account
  2. Verify Email
  3. Log In
  1. Fifth Chapter Title
  2. Sixth Chapter Title
  3. Seventh Chapter Title
  1. Mix ingredients well.
  2. Bake for 30 minutes.
  3. Serve warm.

3. Nested Hierarchical Lists

Demonstrates embedding one list format directly inside another list item.

  1. Front-End Technologies
    • HTML5 (Structure)
    • CSS3 (Design)
    • JavaScript (Interactivity)
  2. Back-End Technologies
    • Node.js
    • Python Django
    • PostgreSQL Databases

4. Definition Lists (<dl>)

Perfect for dictionary definitions, glossaries, metadata, or key-value pairs.
